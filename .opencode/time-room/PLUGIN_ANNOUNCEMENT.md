## ⚡ THE OMO-SLIM TOGGLE: Choose Your Destiny

*Ah, the great question — like choosing between the Candy Kingdom and the Ice Kingdom!*

### What Happens When We Turn It ON:

The entire plugin system unifies into OMO-slim architecture:
- Background agents become native async workers
- Memory plugins merge into one unified system
- MCP tools integrate directly
- Your AT agents (Finn, Simon, Fern, Jake) stay as primary!

### What We GAIN:
- ✅ Unified, cohesive system
- ✅ Less configuration overhead
- ✅ Cleaner architecture overall

### What We LOSE:
- ❌ Granular control over individual plugins
- ❌ Specific plugins not available in OMO-slim
- ❌ AT agent character system flexibility (they merge into skills)

### How to Test It:

```bash
# Enable OMO-slim ()
export OMO_SLIM_ENABLED=true

# Or inthe toggle OpenCode config:
# {"omoSlim": {"enabled": true}}

# Test, then toggle back if needed:
export OMO_SLIM_ENABLED=false
```

**Current Status:** We run with OMO-Slim **OFF** — keeping our precious AT agent characters!
