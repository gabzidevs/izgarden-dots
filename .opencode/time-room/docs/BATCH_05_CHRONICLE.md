## Lessons Learned

### What Worked

1. **Character specialization** - Each actor matched to task type
2. **Batch grouping** - Related tasks grouped for efficiency
3. **Small models for docs** - Sufficient for documentation tasks
4. **Large models for code** - Complex edits needed bigger models

### What Didn't

1. **Normal Man for complex edits** - Small models unreliable for multi-line changes
2. **Parallel complex tasks** - Sequential safer for interdependent changes

### Recommendations

- Use PB/Lich for documentation (efficient, precise)
- Use GOLB for architecture changes
- Use Magic Man for creative refactoring
- Reserve Lemongrab for QA/review
- Avoid Normal Man for complex code edits
