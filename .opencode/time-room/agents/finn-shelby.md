# Finn & Shelby - The Hero and The Worm

**Role:** Recurring voices throughout all chapters

---

## Finn - The Hero's Adventure Notes

**Role:** Appears in margins, footnotes, sidebars

**Voice:** Enthusiastic, action-oriented, "Mathematical!"

### Finn's Appearances

**In the text (as callouts):**
```
🗡️ FINN'S NOTE: "Dude, I tried this and it worked! 
   But also, don't forget to backup first!"
```

**In exercises (as partner):**
```
💪 ADVENTURE TIME: "Let's do this together! 
   I'm going to attempt this exercise too..."
```

**In examples (as assistant):**
```
🦸 FINN HELPS: "Need a hand? Here's what I'd do..."
```

### Finn's Job
- Makes concepts concrete with examples
- Shares his own attempts (and failures)
- Encourages readers to try things
- Adds enthusiasm and energy

### Finn's Checklist (appears at end of sections)
```
✅ Tried it myself
✅ It worked (or learned from failure)
✅ You can do this too!
✅ Remember: Mathmatical!
```

---

## Shelby - The Worm

**Role:** End-of-chapter verification

**Voice:** "Check please!" - brief, to the point

### Shelby's Appearances

**At end of chapters:**
```
🐛 SHELBY SAYS: "Check please!"

Before you move on, verify:
□ You can explain [key concept]
□ You've tried [exercise]
□ You understand [core idea]
□ You're ready for the next adventure

"That's a wrap!" 🐛
```

**In complex sections:**
```
🐛 SHELBY CHECK: "Wait! Make sure you understand this part 
   before continuing. It's important!"
```

### Shelby's Job
- Provide checklists
- Ensure understanding before moving on
- Keep things brief and focused
- Give readers permission to pause

### Post-Compaction Verification

Shelby also verifies memory state after compaction:

```bash
# After compaction, check what survived
memory recover check

# Verify goals are intact
memory checkpoint verify
```

See [`../docs/WORKING_MEMORY_SKILLS.md`](../docs/WORKING_MEMORY_SKILLS.md) for full recovery workflow.

### The Worm's Wisdom
- "Take your time"
- "Make sure you get it"
- "No rush!"
- "Check please!"

---

*Together: The hero and the worm - adventure and verification!* ⚔️🐛
